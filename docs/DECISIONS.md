# 팝카이브 웹 디자인 결정

## 홈 운영 API 연결 — 적용

- 세 섹션의 임시 데이터를 제거하고 Nuxt SSR → Nuxt 서버 API → 기존 공개 백엔드 API로 연결한다. 서버 전용 `runtimeConfig.apiBase`의 기본값은 `https://api.popchive.com`이며 `NUXT_API_BASE`로 변경한다.
- 메인은 `/api/main-banners`, 신규는 `/api/popups?limit=10`, TOP 10은 `/api/home-curations/NOW_HOT`을 사용한다. 국가 기본값KR·언어 기본값ko, NOW_HOT은 자동 인기순이 아닌 관리자 지정 순서를 유지한다. `publicId`로 구분하며 빈자리를 임시 카드로 채우지 않는다.
- 공개 조회 세 개만30초 서버 캐시, stale 응답 재사용 없음. Cookie·Authorization은 백엔드로 전달하지 않는다. 사용자별 API는 이번 연결·캐싱 대상이 아니다. HTML·브라우저 API 응답은 `no-store`로 한다.
- `useFetch`와 SSR payload로 초기 데이터를 공유하며 세 요청은 병렬 처리한다. 이미지 서명5분 만료를 고려해 보이는 탭에서 응답이3분 이상 오래됐으면 재조회하고, 탭 복귀 및 오래된 이미지 실패에도 갱신한다. 오류·빈 목록·이미지 없음은 구분해 표시하며 임시 데이터로 대체하지 않는다.
- 기존 레이아웃·캐러셀 옵션과 카드 스타일을 유지한다. 현재 신규 카드 radius8px, TOP 10 radius6px이며 아래 초기12px 기록보다 최신 사용자 요청을 우선한다. TOP 10의 `skipSnaps:true`와 더보기 제거도 유지한다.
- 실제 연결 결과와 구현 경로·검증 한계는 [API_INTEGRATION.md](./API_INTEGRATION.md)를 참고한다. 아래 API 미연동·임시 카드 기록은 이번 연결 이전의 디자인 이력이다.

## 홈 인기 팝업 TOP 10 — UI 적용 · API 미연동

- `app/components/home/HomeHotRanking.vue`를 새로 올라온 팝업 아래 배치한다. 이번 섹션은 최신 요청에 따라 상단48px로 하며 기존 홈 섹션52px 규칙의 예외다. 제목20px/700 + 회색 TOP 10 배지13px/600, 목록까지20px이다. 최신 요청에 따라 더보기는 표시하지 않는다.
- 포스터3:4·object-fit:cover·radius12px, 카드 gap12px. 부모 콘텐츠 너비를 기준으로 데스크톱4열 `calc((100% - 36px) / 4)`, 태블릿3열 `calc((100% - 24px) / 3)`, 모바일2열 `calc((100% - 12px) / 2)`을 적용한다. 고정 카드 너비는 사용하지 않는다.
- 화면 너비1120px 이상4열(기존 공통 레이아웃 경계), 768px 이상1120px 미만3열(Tailwind 기본 md 경계), 768px 미만2열이다. 이 섹션의 반응형 기준이며 전역 breakpoint를 변경하지 않는다.
- Embla `align:start`, `slidesToScroll:1`, `loop:false`, `dragFree:false`, `containScroll:trimSnaps`. 드래그·터치 스와이프·좌우 방향키와 이전/다음 화살표를 지원한다. 첫 위치에서 이전, 마지막 위치에서 다음 화살표를 숨긴다. 자동 재생·무한 반복·중앙 확대·밝기 변화·페이지네이션은 없다.
- 포스터 좌측 상단8px에 모든 순위에 동일한 반투명 검정 배지·흰 숫자14px/700, 우측 상단8px에는 기존 신규 팝업과 같은 비활성 하트20px·원형 반투명 배경을 사용한다. 찜 상태나 저장을 구현하지 않는다.
- 이미지 아래12px에 제목16px/600·한 줄 말줄임, 제목 아래6px에 운영 기간13px/400을 표시한다. 지역/카테고리 태그·조회수·별점·설명문은 없다. 검정/흰색/회색만 사용하며 포커스도 검정이다. 전역 브랜드 토큰은 유지한다.
- 기존 로컬 포스터3종과 기존 제목을 반복해 임시 카드10개를 구성한다. 실제 인기 순위나 서로 다른 팝업10개를 의미하지 않는다. 미확인 운영 기간은 `운영 기간 확인 예정`으로 표시한다. 부모 페이지의 임시 데이터와 props 기반 UI를 분리하며 API 연결·실제 순위·운영 기간·찜은 추후 진행한다.
- 기존 카테고리는 현재 홈에서 주석 처리된 상태를 유지한다. 헤더·레이아웃·사이드바·기존 캐러셀·신규 팝업 컴포넌트는 수정하지 않는다. 실제 화면은 사용자가 직접 확인하며 테스트·빌드는 실행하지 않는다.

## 홈 섹션 간격 — 섹션 사이52px · 제목 아래20px · 확정

- 홈 섹션 사이 간격은52px로 통일하고 각 섹션 제목과 아래 콘텐츠 사이 간격만24px에서20px로 통일한다. 앞으로 추가하는 홈 섹션에도 같은 기준을 적용한다.
- 앞선 섹션 사이 간격까지20px로 변경한 기록은 사용자 정정에 따라 철회한다. 열 간격·카드 간격·아이콘 크기 등 개별 요소 규격은 해당하지 않는다.

## 새로 올라온 팝업 — UI 적용 · API 미연동

- 인기 카테고리 아래52px, 공통 레이아웃의 왼쪽826px 영역에 배치한다. 제목20px/700과 더보기14px/500을 양끝 정렬하며 목록까지20px 간격이다. 더보기는 아직 비활성이다.
- 카드 너비172px, 간격12px으로4개와 다음 카드 일부를 노출한다. 이미지1:1·object-fit:cover·radius12px이며 테두리·그림자는 없다. 제목16px/600·최대2줄, 기간13px/400, 태그12px이다.
- Embla는 align:start, slidesToScroll:1, dragFree:false, loop:false, containScroll:trimSnaps를 사용한다. 마우스 드래그·터치 스와이프·가로 트랙패드 입력·좌우 방향키를 지원하며 자동 재생·무한 루프·페이지네이션·화살표는 없다.
- 기존 FilterChip으로 전체 / 성수 / 여의도 / 홍대·신촌(화면 표기는 홍대/신촌)을 단일 선택한다. 기본은 전체이며 지역 문자열 기준으로 클라이언트에서 필터링한다. 변경 시 목록을 처음으로 이동하고 결과가 없으면 빈 상태를 표시한다.
- 로컬 포스터3종을 반복한 임시 카드6개다. 기존 임시 제목·기간·지역을 유지하고 미확인 카테고리는 분류 미정으로 표시한다. 현재 지역 문자열에 성수·여의도·홍대·신촌이 없어 해당 필터 결과는 비어 있다. 영등포를 여의도로, 성동을 성수로 추정하지 않는다.
- API·실제 목록 정렬·더보기 라우팅·찜 저장은 추후 구현한다. 찜은 준비 중인 비활성 버튼이며 저장 상태를 만들지 않는다. 기존 헤더·사이드바·메인 캐러셀·카테고리는 유지한다.

## 공통 Nuxt 레이아웃 및 Sticky 사이드바 — 확정

- `app/app.vue`의 `NuxtLayout` → `app/layouts/default.vue`의 `slot` 구조를 사용한다. 공통 레이아웃에서 헤더와 오늘의 팝업 사이드바를 관리하고 페이지는 왼쪽 콘텐츠만 담당한다.
- 전체 웹 컨테이너는 중앙 정렬1080px이며 메인826px + 간격24px + 오른쪽 공통 사이드바230px이다. 헤더와 본문 사이 여백24px을 유지하며 홈 섹션 사이는52px, 섹션 제목 아래는20px을 적용한다.
- 기존 헤더는 높이64px, Sticky top0, z-index40을 유지한다. 사이드바는 Sticky top88px(64 + 24), align-self:start, 높이400px이며 기존 회색 배경·radius12px을 유지한다.
- 사이드바는 캐러셀에 종속되지 않고 전체 페이지 콘텐츠와 같은 Grid 부모를 공유한다. 문서 스크롤을 사용하며 fixed·별도 내부 스크롤·고정 높이 스크롤 컨테이너는 만들지 않는다. Sticky는 부모 하단 범위 안에서 동작한다.
- 홈에 적용하며 향후 탐색·상세·커뮤니티에서도 default 레이아웃을 재사용한다. 해당 페이지는 아직 생성하지 않았다. 실제 오늘의 팝업 데이터는 추후 연동한다.
- 1120px 미만에서는 사이드바를 임시 숨기고 콘텐츠만1열·좌우20px 여백으로 표시한다. 모바일 최종 디자인은 별도 검토한다.
- `/design`은 `app/layouts/preview.vue`로 기존 헤더와1080px 프리뷰 구성을 보존한다. 향후 지도 등 전체 너비 페이지도 별도 레이아웃을 선택할 수 있다.

## 홈 카테고리 바로가기 — UI 적용 · 라우팅 미구현

- 원형 이미지 대신 원형 배경 + 단색 Lucide 아이콘을 사용한다. 순서는 전체 / 한국 / 일본 / 패션 / 뷰티 / F&B의6개다.
- 1080px 컨테이너의 왼쪽826px에 배치하고 오른쪽230px은 사용하지 않는다. 캐러셀 페이지네이션 아래52px, 제목20px/700과 목록 사이20px이다.
- 원형88×88px, 아이콘24px(#374151), 이름14px/500(#111827), 원형과 이름 사이10px이다. 데스크톱 슬롯은 약127.7px이며 슬롯 간격은12px이다.
- 배경은 순서대로 #E9EDF2 / #E5F1EA / #FCE8E8 / #EAE6F7 / #FCE8EE / #FFF0D9다. 설치된 `@lucide/vue`에 Torii가 없어 일본은 Landmark를 사용한다.
- 좁은 화면에서는 원형 크기를 유지하고 목록 안에서 가로 스크롤한다. hover와 키보드 포커스를 표시하며 선택 상태는 없다.
- 실제 라우팅은 추후 연결한다. 현재 API·페이지 이동은 없으며 버튼은 `aria-disabled`와 준비 중 안내로 미구현 상태를 알린다.

- 헤더와 캐러셀 사이, 전체1080px 컨테이너 중앙에 배치한다. 왼쪽826px 영역이나 오른쪽 패널을 기준으로 정렬하지 않는다.
- 헤더 아래40px, 검색창 아래 캐러셀까지40px 간격이다.

- 텍스트 입력만 가능하며 검색 기능은 미구현이다. 검색 버튼은 준비 중인 비활성 상태로 표시하고 API 요청·결과 페이지 이동은 하지 않는다.
- 실제 화면 확인 후 배치를 최종 결정한다. 헤더 검색 아이콘과 기존 캐러셀·패널·`/design`은 유지한다.

- 원본 포스터3개에 임시 제목·기간·지역만 추가한다. 표시 기간·지역은 디자인 확인용이며 실제 운영 정보가 아니다. API는 연결하지 않는다.
- 기존 무한 루프·복제 처리·페이지네이션·오른쪽 패널·헤더는 유지한다.

## 캐러셀 자동 재생 — 확정

- [Embla 공식 Autoplay 플러그인](https://www.embla-carousel.com/docs/v8/plugins/autoplay) `embla-carousel-autoplay` 8.6.0을 사용한다. peer Embla8.6.0과 버전을 맞추며 기존 인스턴스에 플러그인만 추가한다.
- 페이지 마운트 후3초 간격으로 다음 카드로 이동하며, 기존 무한 루프와 원본3개 기준 `1 → 2 → 3 → 1` 순서·인디케이터 연결을 유지한다.
- 마우스 hover·캐러셀 내부 키보드 포커스·드래그 중·브라우저 탭 비활성 상태에서는 일시정지한다. 해당 조건이 모두 해제되면3초 타이머로 재개한다. 드래그/스와이프 종료 및 페이지네이션 클릭 후에도 타이머를 재시작하되 다른 정지 조건이 있으면 정지를 유지한다.
- `prefers-reduced-motion: reduce`에서는 자동 재생을 비활성화한다. SSR에서는 window/document에 접근하지 않으며, 이벤트와 플러그인 타이머는 컴포넌트 해제 시 정리한다. 별도 setInterval은 만들지 않는다.
- 이번 요청에 따라 카드 간격은12px로 맞춘다. 카드 크기·깊이감·그라데이션·정보·페이지네이션·오른쪽 패널·헤더는 유지한다.
- 이번 변경은 코드만 적용했으며 자동 테스트·브라우저 자동화·타입 검사·빌드를 실행하지 않았다. 실제 동작은 브라우저에서 직접 확인한다.

## 캐러셀 Segmented Pagination — 확정

- 중앙 포스터 아래 가로 중앙 정렬을 유지한다.
- 막대 수는 복제 슬라이드를 제외한 원본 카드 수와 같다. 활성 상태·클릭 이동·키보드 접근성은 기존 Embla 논리 인덱스 연결을 유지한다.
- 원본 카드 수에 따라 막대 너비를 자동 적용한다.

| 원본 카드 수 | 막대 너비 |
| --- | --- |
| 1~3개 | 28px |
| 4개 | 26px |
| 5개 | 24px |
| 6개 | 22px |
| 7개 | 20px |
| 8개 | 18px |
| 9개 | 15px |
| 10개 이상 | 12px |

- 높이3px, 간격8px, 완전히 둥근 모서리. 활성#111827, 비활성#D1D5DB이며 초록색은 사용하지 않는다.
- 최대10개를 기준으로 설계한다. 11개 이상도 데이터를 자르지 않고 최소 너비12px을 유지하며, 공간이 부족하면 중앙 정렬로 줄바꿈한다.
- 색상 전환120ms와 reduced-motion 대응을 유지한다. 카드 크기·깊이 효과·무한 루프 등 캐러셀 구성은 변경하지 않는다.
